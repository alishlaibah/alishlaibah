## 👾 About

CS and Math student at UNL. I like building things that actually work for the person using them, where the interface gets out of the way and the system underneath holds up.

That usually means caring about both ends: the low-level stuff that makes something reliable, and the experience that makes it usable without a manual.

- **Currently:** Building a black box recorder for AI coding agents (C + Qt)
- **Interested in:** Systems programming, distributed systems, low-level tooling
- **Stack:** Python and C at the bottom, React and Qt at the top

### Agent Flight Recorder
> Auditing and performance attribution for terminal-based AI coding agents

A **C + Qt** desktop tool that records everything an AI coding agent session does. Logs every file access, command, and child process with timestamps, then correlates it against CPU and memory so you can reconstruct exactly what happened and where it went wrong.
